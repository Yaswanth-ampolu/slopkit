Auto Runner

One button. Walks the WebKit .text range in small chunks, one page load per chunk, and sends every chunk's findings to the sink.

Why chunks. A single 8 MB sweep is about 33,800 carrier reads in one page load, and the tab runs out of memory long before it finishes — which is exactly the failure you are hitting. Scanning 0.25 MB per run is about 1,060 reads, then the page reloads and memory starts clean. The gadget map is assembled from all the chunks afterwards.
